# Intel HEX и BIN Converter

Консольная программа на C++ для преобразования файлов Intel HEX и BIN.


## Возможности

- преобразование Intel HEX в BIN;
- преобразование BIN в Intel HEX;
- выбор стандартных файлов рядом с программой или ввод собственных путей;
- проверка структуры записей Intel HEX и контрольных сумм;
- заполнение промежутков между HEX-адресами байтом `0xFF`.

При преобразовании HEX в BIN выходной файл начинается с наименьшего адреса данных. Поэтому начальный адрес Intel HEX не сохраняется: при обратном преобразовании BIN в HEX адреса начинаются с нуля.


## Запуск

В меню выберите направление преобразования, затем способ задания путей.

При выборе файлов по умолчанию программа использует файлы в папке с `main.exe`:

| Направление | Входной файл | Выходной файл |
|---|---|---|
| HEX → BIN | `hexInput.hex` | `binOutput.bin` |
| BIN → HEX | `binInput.bin` | `hexOutput.hex` |

Файлы `hexInput.hex` и `binInput.bin` в репозитории — примеры входных данных. Выходные файлы создаются программой и не добавляются в Git.


## Структура проекта

- `main.cpp` — меню и выбор файлов;
- `Converter.cpp` / `Converter.h` — преобразование между форматами;
- `IntelHexUtils.cpp` / `IntelHexUtils.h` — чтение и запись записей Intel HEX и бинарных данных.

Программа использует Windows API для определения папки исполняемого файла. Запуск на Windows 7 отдельно не проверялся.
